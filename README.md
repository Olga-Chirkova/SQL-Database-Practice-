# SQL Database Practice

This repository contains SQL practice exercises using MySQL 8.0.

The project is based on a sample educational database called `test_db` and focuses on retrieving, filtering, and analyzing data from relational tables.

## Database

The database includes the following tables:

- `students` — student information
- `courses` — course details
- `instructors` — instructor information
- `enrollments` — student course enrollments
- `grades` — student grades
- `projects` — student projects

## SQL Topics Covered

- SELECT statements
- INNER JOIN and LEFT JOIN
- WHERE clause
- GROUP BY
- Aggregate functions (COUNT)
- Working with primary and foreign keys
- Relationships between multiple tables
- Data retrieval from related tables
